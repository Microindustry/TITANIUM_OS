# 🗺️ MONDO — la banca dati del mondo narrativo (Nina + Sistema)

**Sei in:** `CONTENT_ENGINE/DATABASE/MONDO/` — qui vive TUTTO il materiale del
mondo narrativo. ⚠️ Le fonti CANONICHE (decisioni, linee guida, piani) stanno in
**MENTE** (`MENTE/KNOWLEDGE/MONDO/` + `MENTE/STORIE/`) e sono indicizzate nel RAG;
qui stanno le copie operative e i MATERIALI (grafiche, poster, caroselli).

## La mappa

| Percorso | Cos'è |
|----------|-------|
| `POSTER/CAROSELLI/NINA/` | 🌙 binario NINA: preamboli PRE_01-04 + episodi EP_N2 |
| `POSTER/CAROSELLI/SISTEMA/` | 🔧 binario SISTEMA: PRE_SG_01-04 + episodi EP_SG (voce Matteo) |
| `POSTER/CAROSELLI/_BOZZE/` | 🌒 quarantena dell'apprendista notturno (mai pubblicare da qui) |
| `POSTER/CAROSELLI/_TEMPLATE/` | 🧩 base per ogni carosello nuovo (mai copiare episodi) |
| `POSTER/TAVOLE/` | 🖼️ tavole singole: poster pilota, mappa-mondo, model sheet |
| `POSTER/regioni/` | 💎 card delle 8 Regioni (generate da script) |
| `PERSONAGGI/` · `LOGHI/` | asset visivi dei personaggi e marchi |
| `BIBBIA_DEL_MONDO.md` · `BIBBIA_VISIVA_CAROSELLI.md` · `PONTE… · PIETRE…` | copie di consultazione dei canoni (fonte vera: MENTE) |

## I 3 file da leggere per non perdersi
1. `POSTER/CAROSELLI/README.md` — come funziona la linea di produzione
2. `POSTER/CAROSELLI/NINA/README.md` o `SISTEMA/README.md` — il binario dove lavori
3. `MENTE/KNOWLEDGE/MONDO/GUIDA_CAROSELLI.md` — LE regole operative (fonte unica)
