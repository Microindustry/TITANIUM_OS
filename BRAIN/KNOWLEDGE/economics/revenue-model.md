## Triade dei Flussi (Diversificazione)

| 1 | **Vendita MIMS** (Attacco) | Alti volumi, margine 79% | Entry point ecosistema |

## Business Model MIMS — Cavallo di Troia

```
Hook:       Kit MIMS Light (Eco-Snap) → spesa bassa, impara il sistema
Retention:  Upgrade Quick-Twist → rinforza struttura esistente
Profit:     Tech-Bolt + MIMS HEAVY → alto valore
```

## Hub & Spoke (Fabbrica Liquida)

- **HUB**: R&D + IP + QC + V32 (stampi + prototipazione) — tutto a Matteo
- **SPOKE**: fonderie/laser partner → producono + spediscono
- Modello Pass-Through in fase iniziale: tutto via HUB per QC
- Dima di Controllo "Passa/Non-Passa" prodotta con V32

## Creators Program (Viral R&D)

- Configuratore Web 3D (stile IKEA Kitchen Planner)
- Revenue sharing: royalty ai designer della community
- Catalogo cresce a zero R&D

## Fit Park 4.0

- Accesso App + NFC: €0.50/ingresso (pay-per-use)
- Target operativo: **€2.000/mese**
- Strutture: Zincatura Caldo + Verniciatura Polvere (10 anni nebbia salina)
- Assicurazione Product Liability: ~€50/mese pro-quota nel canone
- Costo refurbishing: <€150/unità
