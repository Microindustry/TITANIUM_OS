### Cos'è
**GENESIS** è il sistema operativo cognitivo dell'ecosistema. Non un assistente generico: un'infrastruttura che gira sul PC fisso 24/7.
- **Memoria/RAG** (`MENTE` → ChromaDB + BM25 + reranker): Claude lavora con il contesto reale del progetto (quote, decisioni, vincoli), non a vuoto.
- **Agenti notturni** che girano da soli: story_agent (commit → episodi), research, night_audit (cartella clinica auto-pulente), AI News Watcher, Self-Improve (propone, l'umano approva), inventario, pct_sync (coerenza % dalla fonte unica STATE).
- **Dashboard React** (viste, mappe, CV, critiche) + **API Flask** + **MCP** (Claude Code parla col sistema) + **n8n** locale.
- **Sicurezza**: API blindata (denylist .env/_VAULT, auth fail-closed da remoto), segreti in `_VAULT`.

### Il principio
**1 input → N output.** Ogni lavoro fisico reale genera conoscenza, contenuto e capacità digitale; quella capacità rende l'officina più produttiva. Il loop è il prodotto.

### Il ruolo
È il **collante**: V32, MIMS, EVA, Nina, il CV — tutto gira qui sopra. È ciò che trasforma un artigiano bravo in un artigiano che **scala** senza assumere.
